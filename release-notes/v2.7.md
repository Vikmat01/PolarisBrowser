## Polaris Browser 2.7

Новое поведение адресной панели:

- **Прокрутка** — панель сжимается в мини-капсулу с адресом сайта, контент почти не перекрыт.
- **Тап по капсуле** — снова полная панель.
- **Свайп вниз** по панели или капсуле — панель прячется целиком, внизу остаётся тонкая полоска. Удобно на страницах без прокрутки.
- **Свайп вверх (или тап) по полоске** — панель возвращается.
